# O&O Frontend

2026 멋쟁이사자처럼 중앙 해커톤 1조 오레오팀의 프론트엔드 레포지토리입니다.

## 프로젝트 소개

오프라인과 온라인의 경험을 연결하는 서비스를 개발합니다.

## 기술 스택

- React
- JavaScript
- Vite
- React Router DOM
- styled-components
- Axios
- Zustand


## 폴더 구조

```text
src
├─ apis          # 서버 API 요청 관련
├─ assets        # 이미지, 아이콘, 폰트
├─ components    # 공통 컴포넌트
├─ contexts      # Context API 기반 공용 상태
├─ hooks         # 커스텀 훅
├─ pages         # 페이지 컴포넌트
├─ router        # 페이지 경로 설정
├─ styles        # theme, 전역 및 공통 스타일
├─ App.jsx
└─ main.jsx
```
